# Beginner Python Projects

Two simple Python programs for practicing basic programming concepts:

1. **Basic Calculator** — performs addition, subtraction, multiplication, and division.
2. **Number Guessing Game** — guess a randomly selected number between 1 and 100.

## Requirements

- Python 3

## How to Run

Download or clone this repository, then open a terminal in the project folder.

### Basic Calculator

```bash
python calculator.py
```

### Number Guessing Game

```bash
python number_guessing_game.py
```

On some systems, use `python3` instead of `python`.

These projects are intended for beginners learning Python, including user input, conditionals, loops, and the `random` module.
